# Make it yours

Read CLAUDE.md and the current schema. Clarify the requested field, label, schedule metric or rule. Back up the database before applying a change. Add the next numbered migration instead of rewriting applied migrations, update the CLI and the matching command recipe, and add a test for the changed business behaviour. Run npm test in isolated data, apply npm run migrate to the intended database, and read back the result. Never delete records or change retention periods without an explicit instruction. Keep CLAUDE.md and AGENTS.md using the same command library.
